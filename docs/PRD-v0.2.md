# ai学 产品规划文档 v0.2

> 一个 AI 驱动的互动式学习伴侣。第一个深度用户：eggLi（计算机考研备考）。
> 形态：前后端分离；移动端 Android 优先（iOS 后置）；后端运行于局域网 Windows 电脑。

---

## 1. 产品定位

**一句话**：AI 教练 + 个人学习闭环系统。AI 不只是问答工具，而是知晓你的课程安排、知识薄弱点、学习节奏，主动安排任务、主动答疑、主动出题、主动复习的陪伴式教练。

**核心原则**：
- 数据飞轮：每次互动都沉淀为知识资产（知识树生长、掌握度更新），而不是用完即弃的对话
- AI 主动，用户省心：提醒、出题、复习都由系统推动，用户只需"学"
- 单用户优先，架构留多用户余地

## 2. 核心闭环

```
课程表 → 规划Agent生成任务清单 → 任务界面按时间流转(课前/课中/课后)
   ↑                                                      ↓
掌握度更新 ← 答题结果/AI判定 ← 出题Agent生成巩固题 ← 答疑互动(带RAG)
   ↓
知识树生长 → 薄弱节点 → 影响下一轮任务生成和出题难度 ←
```

四个界面 + 管理台共同驱动这个环。任何一环的产出都进入下一环。

## 3. 功能详设

### 3.1 任务界面（学习会话状态机）

**概念**：一次"上课"是一个学习会话（Study Session），有明确的生命周期。

**状态机**：
```
未开始 → 课前(预习, T-15min) → 课中(跟随, 上课时间到) → 课后(巩固, 课后30min) → 完成/逾期
```

**课中模式（全屏）**：
- 顶部：本课目标（规划 Agent 从课程大纲生成，1-3 条）
- 中部：任务卡片流。每张卡片：类型（阅读/练习/记忆/思考）、预计时长、状态（未开始/进行中/完成/跳过）
- 每个任务卡片可一键"问 AI"（跳转答疑，自动带上任务上下文）

**任务来源**：规划 Agent 按"课程内容 + 当前知识薄弱点"在课前生成，可人工在管理台调整。

**课后巩固**：AI 出 3-5 道巩固题 + 一段复盘（总结本课互动中的疑点）。

**逾期**：未完成任务进复习队列，不影响新任务，但会出现在"我的"复习卡片里。

### 3.2 答疑互动界面

三种模式：
1. **自由问**：流式回答。回答中自动标注涉及的知识点（链接到知识树节点，可点击跳转）
2. **做题**：AI 按知识点 + 难度出题，优先薄弱点。题型：选择/填空/简答/代码题
3. **小测**：5 题快测，结束后输出掌握度诊断（哪些知识点稳、哪些要补）

**沉淀机制**（每轮对话结束）：
- AI 生成"沉淀建议"：新概念 / 纠正过的错误认知 / 值得记录的关键结论
- 用户确认后写入知识库（来源=答疑沉淀）

**复习节奏**：答疑中涉及的知识点进入复习队列：1 天后、3 天后、7 天后各出一题。

**RAG**：答疑时先检索知识库相关节点（自己笔记/错题优先），再补充通用知识，回答带引用来源。

### 3.3 知识库（知识树 = 能力画像）

**结构**：科目 → 章节 → 知识点（多级）。示例：408 → 数据结构 → 树 → 平衡二叉树 → 旋转操作。

**知识点属性**：
| 字段 | 说明 |
|---|---|
| 难度 | 1-5 |
| 掌握度 | 0-100，做题正确率 + AI 对话判定共同更新 |
| 状态 | 未学 / 学习中 / 已掌握 / 待复习 |
| 来源 | 用户提问 / 答疑沉淀 / 手动录入 / AI 生成 |
| 关联题目 | FID 列表 |

**前端**：树状浏览、按科目展开、按难度过滤、按掌握度热力着色（越低越红）。
**管理台**：增删改、从课本目录粘贴生成骨架、批量导入导出。

### 3.4 我的界面

- **AI 教练人格**：名称/性格/语气可自定义，显示为"教练卡片"
- **数据**：连续学习天数、本周学时、科目掌握度雷达图、复习队列、GitHub 风格学习热力图
- **设置**：模型选择（DeepSeek/千问/豆包）、API 配置、人格设定、数据导出

### 3.5 管理台（后端配套，/admin）

- 课程表管理（周模板 + 特殊日期）
- 知识树管理（全量增删改 + 骨架生成）
- 任务生成配置（每课默认任务模板）
- AI 设定（人格、出题难度偏好、复习节奏参数）
- 数据浏览（会话记录、掌握度明细）

## 4. 数据模型（草案）

users
courses（科目）
schedule_items（周课表条目：课程、时间、地点/教室、周几）
study_sessions（学习会话：课程、日期、状态机）
tasks（任务：会话ID、类型、内容、预计时长、状态、顺序）
conversations / messages（答疑会话与消息）
knowledge_nodes（知识树节点：父子、科目、难度、掌握度、状态、来源）
mastery_records（掌握度变更流水：节点、旧值、新值、触发原因）
quiz_questions / quiz_answers（题目与作答）
review_queue（复习队列：节点、到期日、状态）

## 5. AI 编排层（四个角色）

1. **规划 Agent**：读课程表 + 薄弱点 → 生成学习会话任务清单（课前/课中/课后）
2. **答疑 Agent**：自由问答 + RAG，流式输出，知识点标注
3. **出题 Agent**：按知识点/难度/题型生成，JSON Schema 输出，作答后判定
4. **掌握度裁判**：规则 + AI 混合。做题正确率直接更新（规则）；答疑中 AI 判断概念混淆可下调（AI）

模型路由：统一 OpenAI 兼容网关，可配置每角色的模型与参数。记录 token 用量。

## 6. 技术选型（已定）

| 层 | 选择 | 备注 |
|---|---|---|
| 移动端 | Flutter | Android 优先，iOS 后置，同一套代码 |
| 后端 | Python FastAPI | SQLAlchemy + APScheduler + WebSocket + SSE |
| 数据库 | SQLite → PostgreSQL | 单机起步 |
| 管理台 | Vue3 SPA 打包进 FastAPI | /admin 路由 |
| AI | OpenAI 兼容网关 | DeepSeek / 千问 / 豆包 可切换 |
| 认证 | 设备 PIN（前期）→ JWT（多用户） | 局域网 |

| M6 | 打磨：iOS 适配、多设备同步、多用户 | 发布 |

## 8. 开放问题

- 课程表录入方式：手动 / 从考研机构课表导入 / 半自动？
- 答疑的知识点标注粒度（自动识别还是半自动确认）？
- 是否要"错题本"独立界面（当前归入知识树关联题）？
- 数据导出格式（Markdown 笔记 / JSON 全量）？
- App 是否需要离线可用（学习任务缓存）？
