# ai学 UI/CSS 美化方案 v2.0

> 基于 v1.0「晨光 / 专注 / 纸感 / 克制」设计理念的全面美化升级
> 生成日期：2026-08-30
> 配套文件：`prototype/design-tokens-v2.css`、`assets/` 视觉素材库

---

## 一、方案总览

### 1.1 升级目标

在不颠覆 v1.0 核心设计语言的前提下，从「能用」升级到「想用」：

| 维度 | v1.0 现状 | v2.0 目标 |
|---|---|---|
| 视觉层次 | 平面卡片 + 单级阴影 | 渐变 + 玻璃拟态 + 三级阴影层次 |
| 图标 | 内联 SVG 线性图标 | 统一图标体系（线性/面性双套）+ App 图标 |
| 插画 | 无 | 空状态/庆祝/学习场景插画库 |
| 动效 | 基础 transition | 标准化曲线 + 微交互（涟漪/浮动/脉冲） |
| 组件 | 12 个基础组件 | 27 个组件（新增启动页/Toast/底部弹层/骨架屏等） |
| 深色模式 | 变量覆盖 | 玻璃拟态 + 发光阴影适配 |

### 1.2 设计理念延续与进化

- **晨光** → 新增渐变光晕、启动页品牌光效
- **专注** → 课中模式增强沉浸感（渐变头 + 装饰光斑）
- **纸感** → 卡片渐变底色 + 内阴影，更接近真实纸张
- **克制** → 动效 ≤400ms，无弹跳，尊重 `prefers-reduced-motion`

## 二、App 软件图标方案

已生成 3 套风格方案，位于 `assets/app-icon/`：

### 方案 A：现代渐变风（推荐）

- **文件**：`app-icon-gradient.png`
- **风格**：蓝紫渐变背景（#3E63DD → #8A5CD6），白色线条符号
- **符号**：打开的书本 + 大脑/神经网络节点融合
- **适用**：iOS / Android 主流应用商店，科技感与学习感平衡
- **记忆点**：渐变色彩在手机桌面辨识度高，书本+大脑直接传达「AI 学习」

### 方案 B：温暖纸感风

- **文件**：`app-icon-paper.png`
- **风格**：米白纸感背景（#F6F6F2），手绘风打开书本 + 知识节点 + 小太阳
- **适用**：教育类产品调性，温暖治愈，降低学习压力感
- **记忆点**：晨光小太阳呼应「晨光」设计理念，手绘风有亲和力

### 方案 C：极简几何风

- **文件**：`app-icon-minimal.png`
- **风格**：深色背景（#1C1B1A），蓝紫渐变发光线条构成的「A」字母变形
- **符号**：A 的横杠变为发光进度环，象征学习进度
- **适用**：极客/技术向用户，深色桌面模式下辨识度极高
- **记忆点**：字母 A = AI + ai学，进度环暗示持续进步

### 选型建议

| 场景 | 推荐方案 |
|---|---|
| 主 App 图标（应用商店） | 方案 A（渐变风，辨识度最高） |
| 品牌周边/社交媒体 | 方案 B（纸感风，有温度） |
| 深色模式快捷方式/开发者版 | 方案 C（极简风，科技感） |

### 多尺寸导出规范

```
iOS:    1024×1024 (App Store) / 180×180 (iPhone @3x) / 120×120 (@2x)
Android: 512×512 (Play Store) / 192×192 (xxxhdpi) / 144×144 (xxhdpi)
Web:    192×192 (PWA) / 32×32 (favicon) / 16×16 (favicon)
```

## 九、验收标准

1. **视觉一致性**：所有界面使用 v2.0 变量，无硬编码色值
2. **图标统一**：导航/科目/任务类型图标风格统一，尺寸符合规范
3. **动效克制**：所有动画 ≤400ms，无弹跳，尊重 reduced-motion
4. **深色模式**：切换深色模式后所有组件正常显示，玻璃拟态适配
5. **空状态**：所有列表页均有空状态插画 + 引导文字
6. **响应式**：390px 手机宽度下无横向滚动，组件不溢出
7. **无障碍**：可聚焦元素有焦点环，文字对比度 ≥4.5:1
