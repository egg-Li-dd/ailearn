## 一、现状分析

### 现有模型

| 表 | 文件 | 字段 | 说明 |
|----|------|------|------|
| `courses` | `models/course.py` | id, name, subject_code, color, sort | 科目 |
| `schedule_items` | `models/course.py` | id, course_id, weekday, start_time, end_time, location, is_active | 周课表项 |
| `schedule_exceptions` | `models/course.py` | id, date, action, course_id, start_time, end_time | 日期例外 |
| `knowledge_nodes` | `models/knowledge.py` | id, parent_id, subject_id, name, level, difficulty, mastery, status, source, summary, quiz_ids, created_at, updated_at | 知识树节点（已支持无限层级） |
| `mastery_records` | `models/knowledge.py` | id, node_id, old_value, new_value, reason, source, created_at | 掌握度流水 |

### 现有路由

| 路由文件 | 前缀 | 已有能力 |
|----------|------|----------|
| `routers/course.py` | `/api/v1` | 科目 CRUD、课表项 CRUD（含时间冲突检测）、例外 CRUD |
| `routers/knowledge.py` | `/api/v1/knowledge` | 递归树获取、节点搜索、节点 CRUD、AI 导入大纲、掌握度更新 |

### 现有迁移机制

`core/migrate.py` 使用轻量迁移：
- `_ALTERS` 字典定义 `ALTER TABLE` 语句
- 启动时自动检测列是否存在，不存在则执行
- 建表由 SQLAlchemy `create_all` 负责

### 关键发现

1. **知识树已支持无限层级**：`parent_id` 自引用 + `_node_out` 递归输出，后端无需大改，主要是前端硬编码 3 层的问题
2. **掌握度流水已存在**：`MasteryRecord` 表已有，可直接用于掌握度历史查询
3. **冲突检测已实现**：`_conflict` 函数已有，可复用到拖拽移动场景
4. **迁移机制轻量**：新增字段只需在 `_ALTERS` 中添加 ALTER 语句

## 二、数据模型变更

### 2.1 courses 表 — 新增字段

```python
# models/course.py
class Course(Base):
    __tablename__ = "courses"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(64))
    subject_code: Mapped[str | None] = mapped_column(String(16))
    color: Mapped[str | None] = mapped_column(String(16))
    sort: Mapped[int] = mapped_column(Integer, default=0)

    # === 新增字段 ===
    icon: Mapped[str | None] = mapped_column(String(32))       # 科目图标 emoji，如 📐📝🌍
    description: Mapped[str | None] = mapped_column(Text)       # 科目描述
    is_archived: Mapped[bool] = mapped_column(Boolean, default=False)  # 归档标记
```

**变更说明**：
- `icon`：科目卡片显示的 emoji 图标
- `description`：科目详情面板显示的描述文本
- `is_archived`：软删除/归档，不删除关联数据，列表默认不显示归档科目

### 2.2 schedule_items 表 — 新增字段

```python
# models/course.py
class ScheduleItem(Base):
    __tablename__ = "schedule_items"

    id: Mapped[int] = mapped_column(primary_key=True)
    course_id: Mapped[int] = mapped_column(ForeignKey("courses.id"))
    weekday: Mapped[int] = mapped_column(Integer)
    start_time: Mapped[time] = mapped_column(Time)
    end_time: Mapped[time] = mapped_column(Time)
    location: Mapped[str | None] = mapped_column(String(128))
    is_active: Mapped[bool] = mapped_column(Boolean, default=True)

    # === 新增字段 ===
    teacher: Mapped[str | None] = mapped_column(String(64))          # 教师姓名
    classroom: Mapped[str | None] = mapped_column(String(64))        # 教室（与 location 区分，location 保留兼容）
    week_type: Mapped[str] = mapped_column(String(8), default="all") # 单双周：all/odd/even
    color_override: Mapped[str | None] = mapped_column(String(16))   # 单独覆盖科目配色
    sort: Mapped[int] = mapped_column(Integer, default=0)             # 同时段排序（拖拽用）
```

**变更说明**：
- `teacher`：教师字段，课表项详情显示
- `classroom`：教室字段，与现有 `location` 并存（location 保留兼容，后续可统一）
- `week_type`：单双周支持，`all`=全周，`odd`=单周，`even`=双周
- `color_override`：课表项单独配色，覆盖科目默认配色
- `sort`：同时段内的排序，用于拖拽调整顺序

### 2.3 schedule_exceptions 表 — 新增字段

```python
# models/course.py
class ScheduleException(Base):
    __tablename__ = "schedule_exceptions"

    id: Mapped[int] = mapped_column(primary_key=True)
    date: Mapped[date] = mapped_column(Date, index=True)
    action: Mapped[str] = mapped_column(String(8), default=ScheduleAction.REMOVE)
    course_id: Mapped[int | None] = mapped_column(ForeignKey("courses.id"))
    start_time: Mapped[time | None] = mapped_column(Time)
    end_time: Mapped[time | None] = mapped_column(Time)

    # === 新增字段 ===
    reason: Mapped[str | None] = mapped_column(String(256))           # 例外原因（国庆放假/校运动会等）
    repeat_type: Mapped[str] = mapped_column(String(16), default="none")  # 重复类型：none/daily/weekly/biweekly/monthly
    repeat_config: Mapped[str | None] = mapped_column(Text)           # 重复配置 JSON（如 {"weekdays":[1,3],"end_date":"2026-12-31"}）
    is_active: Mapped[bool] = mapped_column(Boolean, default=True)    # 启用/停用
```

**变更说明**：
- `reason`：例外原因，月历视图 hover 显示
- `repeat_type` + `repeat_config`：重复规则支持，如"每周三停课"
- `is_active`：启用/停用重复例外，不删除数据

### 2.4 knowledge_nodes 表 — 新增字段

```python
# models/knowledge.py
class KnowledgeNode(Base):
    __tablename__ = "knowledge_nodes"

    id: Mapped[int] = mapped_column(primary_key=True)
    parent_id: Mapped[int | None] = mapped_column(ForeignKey("knowledge_nodes.id"))
    subject_id: Mapped[int | None] = mapped_column(ForeignKey("courses.id"))
    name: Mapped[str] = mapped_column(String(128))
    level: Mapped[int] = mapped_column(Integer, default=1)
    difficulty: Mapped[int] = mapped_column(Integer, default=1)
    mastery: Mapped[int] = mapped_column(Integer, default=0)
    status: Mapped[str] = mapped_column(String(16), default="untouched")
    source: Mapped[str] = mapped_column(String(16), default="manual")
    summary: Mapped[str | None] = mapped_column(Text)
    quiz_ids: Mapped[str | None] = mapped_column(Text)
    created_at: Mapped[datetime] = mapped_column(default=utcnow)
    updated_at: Mapped[datetime] = mapped_column(default=utcnow, onupdate=utcnow)

    # === 新增字段 ===
    sort: Mapped[int] = mapped_column(Integer, default=0)             # 同级排序（拖拽用）
    icon: Mapped[str | None] = mapped_column(String(32))              # 节点图标 emoji
    notes: Mapped[str | None] = mapped_column(Text)                   # 学习笔记/要点/常见误区
    prerequisites: Mapped[str | None] = mapped_column(Text)           # 前置知识点 ID 列表 JSON（如 [1,2,3]）
```

**变更说明**：
- `sort`：同级节点排序，拖拽调整顺序时更新
- `icon`：节点图标，树视图和思维导图显示
- `notes`：节点备注，详情面板显示，支持富文本（纯文本存储，前端渲染 Markdown）
- `prerequisites`：前置知识点关联，JSON 数组存储 ID 列表

### 2.6 新增表：audit_logs（审计日志）

```python
# models/audit.py（新建文件）
class AuditLog(Base):
    """操作审计日志：记录关键写操作。"""
    __tablename__ = "audit_logs"

    id: Mapped[int] = mapped_column(primary_key=True)
    module: Mapped[str] = mapped_column(String(32), index=True)       # 模块：course/schedule/exception/knowledge/ai
    action: Mapped[str] = mapped_column(String(16), index=True)       # 操作：create/update/delete/batch_delete/import
    target_id: Mapped[int | None] = mapped_column(Integer)             # 操作对象 ID
    target_name: Mapped[str | None] = mapped_column(String(256))       # 操作对象名称（冗余，便于展示）
    detail: Mapped[str | None] = mapped_column(Text)                   # 变更详情 JSON（如 {"old":..., "new":...}）
    operator: Mapped[str] = mapped_column(String(32), default="admin") # 操作人
    created_at: Mapped[datetime] = mapped_column(default=utcnow, index=True)
```

**变更说明**：
- 记录删除、批量修改、AI 导入等关键操作
- 支持按模块/操作/时间范围查询
- `detail` 字段存储变更前后数据，便于追溯

```python
def recalc_parent_mastery(db, node_id: int) -> None:
    """父节点掌握度 = 子节点掌握度加权平均（按题目数加权，无题目则按节点数）。"""
    node = db.get(KnowledgeNode, node_id)
    if not node or node.parent_id is None:
        return
    children = list(db.scalars(
        select(KnowledgeNode).where(KnowledgeNode.parent_id == node.parent_id)
    ))
    if not children:
        return
    # 加权平均
    total_weight = sum(c.quiz_count or 1 for c in children)
    weighted_sum = sum(c.mastery * (c.quiz_count or 1) for c in children)
    parent = db.get(KnowledgeNode, node.parent_id)
    parent.mastery = int(weighted_sum / total_weight)
    db.commit()
    # 递归向上
    recalc_parent_mastery(db, parent.id)
```

## 六、技术要点与实现细节

### 6.1 知识树递归查询优化（N+1 问题）

**现状问题**：`_node_out` 函数对每个节点执行一次子查询，N 个节点产生 N+1 次查询。

**优化方案**：一次性加载所有节点，在内存中构建树。

```python
def build_tree_efficient(db, subject_id=None, search=None, mastery_filter=None):
    """一次性查询所有节点，内存构建递归树，避免 N+1。"""
    stmt = select(KnowledgeNode)
    if subject_id is not None:
        # 只查该科目的根节点及其所有子孙（需要递归 CTE 或先查根再查全部）
        roots = list(db.scalars(
            select(KnowledgeNode.id).where(
                KnowledgeNode.parent_id.is_(None),
                KnowledgeNode.subject_id == subject_id
            )
        ))
        if not roots:
            return []
        # 递归 CTE 获取所有子孙 ID
        cte = select(KnowledgeNode.id).where(KnowledgeNode.id.in_(roots)).cte(recursive=True)
        cte = cte.union_all(
            select(KnowledgeNode.id).where(KnowledgeNode.parent_id == cte.c.id)
        )
        all_ids = [r[0] for r in db.execute(select(cte.c.id)).fetchall()]
        stmt = stmt.where(KnowledgeNode.id.in_(all_ids))

    nodes = list(db.scalars(stmt.order_by(KnowledgeNode.sort, KnowledgeNode.id)))

    # 搜索过滤
    if search:
        matched_ids = {n.id for n in nodes if search in n.name}
        # 保留匹配节点及其所有祖先
        keep_ids = set(matched_ids)
        node_map = {n.id: n for n in nodes}
        for nid in matched_ids:
            cur = node_map[nid]
            while cur.parent_id and cur.parent_id in node_map:
                keep_ids.add(cur.parent_id)
                cur = node_map[cur.parent_id]
        nodes = [n for n in nodes if n.id in keep_ids]

    # 掌握度过滤
    if mastery_filter:
        nodes = [n for n in nodes if mastery_filter(n.mastery)]

    # 内存构建树
    node_map = {n.id: _node_to_dict(n) for n in nodes}
    roots = []
    for n in nodes:
        if n.parent_id is None:
            roots.append(node_map[n.id])
        elif n.parent_id in node_map:
            node_map[n.parent_id]["children"].append(node_map[n.id])
    return roots
```

### 6.2 拖拽移动循环引用校验

```python
def is_descendant(db, ancestor_id: int, node_id: int) -> bool:
    """判断 node_id 是否是 ancestor_id 的子孙节点（防止循环引用）。"""
    if ancestor_id == node_id:
        return True
    # 递归 CTE
    cte = select(KnowledgeNode.id).where(KnowledgeNode.id == ancestor_id).cte(recursive=True)
    cte = cte.union_all(
        select(KnowledgeNode.id).where(KnowledgeNode.parent_id == cte.c.id)
    )
    result = db.execute(select(cte.c.id).where(cte.c.id == node_id)).first()
    return result is not None

def move_node(db, node_id, parent_id, sort):
    if parent_id is not None:
        if is_descendant(db, node_id, parent_id):
            raise HTTPException(422, "不能将节点移动到自己的子孙节点下")
    node = db.get(KnowledgeNode, node_id)
    node.parent_id = parent_id
    node.sort = sort
    node.level = _infer_level(db, parent_id, None)
    db.commit()
    return node
```

### 6.3 重复例外展开

```python
from datetime import date, timedelta

def expand_repeat_exception(exc, start: date, end: date) -> list[date]:
    """将重复例外展开为指定日期范围内的实际日期列表。"""
    if exc.repeat_type == "none":
        return [exc.date] if start <= exc.date <= end else []

    config = json.loads(exc.repeat_config or "{}")
    dates = []
    current = max(start, exc.date)

    if exc.repeat_type == "daily":
        while current <= end:
            dates.append(current)
            current += timedelta(days=1)

    elif exc.repeat_type == "weekly":
        weekdays = config.get("weekdays", [exc.date.weekday()])
        while current <= end:
            if current.weekday() in weekdays:
                dates.append(current)
            current += timedelta(days=1)

    elif exc.repeat_type == "biweekly":
        weekdays = config.get("weekdays", [exc.date.weekday()])
        week_offset = (exc.date - start).days // 7 % 2
        while current <= end:
            current_week = (current - start).days // 7
            if current.weekday() in weekdays and current_week % 2 == week_offset:
                dates.append(current)
            current += timedelta(days=1)

    elif exc.repeat_type == "monthly":
        month_days = config.get("month_days", [exc.date.day])
        while current <= end:
            if current.day in month_days:
                dates.append(current)
            current += timedelta(days=1)

    # 结束日期限制
    end_date = config.get("end_date")
    if end_date:
        end_date = date.fromisoformat(end_date)
        dates = [d for d in dates if d <= end_date]

    return dates
```

### 6.4 课表网格冲突检测

```python
def get_grid_data(db, week_type="all", target_date=None):
    """获取网格视图数据，同时检测冲突。"""
    stmt = select(ScheduleItem).where(ScheduleItem.is_active.is_(True))
    if week_type != "all":
        stmt = stmt.where(ScheduleItem.week_type.in_(["all", week_type]))
    items = list(db.scalars(stmt))

    # 按 weekday + 时间段分组
    grid = {}
    for item in items:
        weekday = str(item.weekday)
        if weekday not in grid:
            grid[weekday] = {}
        # 按开始时间作为 key（精确到分钟）
        time_key = item.start_time.strftime("%H:%M")
        if time_key not in grid[weekday]:
            grid[weekday][time_key] = []
        grid[weekday][time_key].append(item)

    # 检测冲突：同一时段有多个课表项
    conflicts = []
    for weekday, times in grid.items():
        for time_key, items_at_time in times.items():
            if len(items_at_time) > 1:
                for item in items_at_time:
                    conflicts.append({
                        "item_id": item.id,
                        "weekday": int(weekday),
                        "time": time_key,
                        "conflict_with": [
                            {"id": i.id, "course_name": db.get(Course, i.course_id).name}
                            for i in items_at_time if i.id != item.id
                        ]
                    })

    return {"grid": grid, "conflicts": conflicts}
```

            return result
        return wrapper
    return decorator

### 决策 1：知识树级联删除 vs 禁止删除有子节点的节点

**现状**：删除有子节点的节点时返回 409 错误，要求先删除子节点。

**方案**：增加 `cascade` 查询参数，默认 `false`（保持现有行为），`true` 时级联删除所有子孙节点。

**原因**：
- 保持向后兼容
- 管理台批量操作时需要级联删除
- 级联删除记录审计日志，便于恢复

### 决策 2：重复例外存储方式

**方案**：不预生成所有日期，存储重复规则，查询时动态展开。

**原因**：
- 预生成会产生大量数据（如"每周三停课"持续一年 = 52 条记录）
- 动态展开灵活，修改规则不需要更新所有记录
- 月历视图查询时只展开当月，性能可控

### 决策 3：课表模板存储方式

**方案**：JSON 快照存储，不建立模板-课表项关联表。

**原因**：
- 模板是快照，应用后与原模板无关联
- JSON 存储简单，不需要复杂的关联查询
- 应用模板时清空现有课表项，从 JSON 恢复

### 决策 4：知识树 N+1 查询优化

**方案**：一次性查询所有节点，内存构建递归树。

**原因**：
- 现有 `_node_out` 递归函数对每个节点执行一次查询，节点多时性能差
- 一次性查询 + 内存构建，时间复杂度 O(N)
- SQLite 递归 CTE 支持良好，可用于按科目过滤子孙节点
